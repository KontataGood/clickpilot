
# ClickPilot

ClickPilot — desktop-приложение для автоматизации повторяющихся кликов мышью.

## Возможности

- Выбор точки клика с помощью F5.
- Запуск и остановка автокликера с помощью F6.
- Настройка интервала и типа клика.
- Сохранение пользовательских настроек.
- Журнал активности с экспортом.

## Запуск из исходников

Требуется Python 3.12 или совместимая версия.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run_clickpilot.py
```

## Сборка для Windows

Установите зависимости разработчика:

```powershell
python -m pip install -r requirements-dev.txt
python -m PyInstaller --noconfirm --clean clickpilot.spec
```

Готовая сборка появится в `dist/ClickPilot/`.

## Управление

- **F5** — выбрать точку клика.
- **F6** — запустить или остановить автокликер.

## Безопасность

Перед запуском проверьте выбранную точку и интервал. Не используйте автокликер там, где автоматизация запрещена правилами сервиса или приложения.
