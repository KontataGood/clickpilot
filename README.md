# ClickPilot

ClickPilot — desktop-приложение для автоматизации повторяющихся кликов мышью в Windows.

## Возможности

- Выбор точки клика с помощью горячей клавиши.
- Запуск и остановка автокликера.
- Настройка интервала между кликами и типа клика.
- Настраиваемые горячие клавиши.
- Сохранение настроек и поддержка профилей.
- Журнал активности с возможностью экспорта.
- Сворачивание приложения в системный трей.
- Автозапуск вместе с Windows.
- Тёмный интерфейс.

## Требования

- Windows.
- Python 3.12 для запуска из исходного кода.

## Запуск из исходного кода

Клонируйте репозиторий и перейдите в его каталог. Затем выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run_clickpilot.py
```

## Сборка для Windows

Установите зависимости разработчика и соберите приложение:

```powershell
python -m pip install -r requirements-dev.txt
python -m PyInstaller --noconfirm --clean clickpilot.spec
```

Готовая сборка появится в каталоге `dist/ClickPilot/`. Для запуска используйте `ClickPilot.exe`.

## Управление

По умолчанию:

- **F5** — выбор точки клика.
- **F6** — запуск или остановка автокликера.

Горячие клавиши можно изменить в настройках приложения.

## Автозапуск

На странице «Настройки» включите параметр «Запускать вместе с Windows». Приложение будет запускаться при входе в учётную запись текущего пользователя.

Для отключения автозапуска снимите этот флажок.

## Безопасность

Перед запуском проверьте выбранную точку и интервал кликов. Не используйте автокликер там, где автоматизация запрещена правилами сервиса или приложения.
